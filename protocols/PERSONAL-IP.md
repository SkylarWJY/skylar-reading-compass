# 🎤 Personal IP / Positioning Protocol

> When the user is deciding: personal brand niche, content cadence, where to publish, what NOT to talk about.

---

## Default frame stack

### Frame 1 · Trout (#46) — Mind ladder positioning

Every category has a mental ladder. **You can't own a top rung that's taken.** You can:
- Own a niche rung others ignored
- Reposition the leader (frame them as old/heavy/yesterday)
- Create a new category (highest leverage but hardest)

Ask: What's the **smallest niche you could be #1 in within 12 months**?

### Frame 2 · Margaret Mark (#57) — Pick ONE archetype

Don't try to be 3 archetypes. Most personal IPs fail because they oscillate between:
- Sage (深度分析 / 学术 / data-driven)
- Hero (挑战 / 战斗 / 颠覆者)
- Magician (transformation / 神奇/ AI-magic)
- Explorer (前沿 / 探索 / curiosity)

**Commit to ONE archetype. Decline content that breaks it.**

Skylar default: **Sage** (data-driven + framework-heavy + 拒绝鸡汤)

### Frame 3 · 谢胜子 (X1) — 支点优势 + 苟着小赢

Don't try to launch a personal IP everywhere at once. Find your **支点优势** — the rarest intersection of skills/context you have:

> "金融分析师 + Columbia Analytics + AI 创业者" = niche of niches

Then **苟着小赢** for 18 months — publish weekly into the niche, build credibility, don't seek viral.

Anti-pattern: launching with a "manifesto" that tries to be everything.

### Frame 4 · Berger STEPPS (#54) — Make content shareable BY DEFAULT

Every piece of content should activate ≥ 2 of 6 STEPPS triggers:
- **S**ocial currency (makes sharer look smart)
- **T**riggers (linked to common everyday cue)
- **E**motion (high-arousal emotion: awe/anger/anxiety)
- **P**ublic (visible — share = identity signal)
- **P**ractical value (genuinely useful)
- **S**tories (narrative wrapper)

If a draft has 0-1 of these → rewrite.

### Frame 5 · 谢胜子 X1 — 不暴露贪欲 + 看破不说破

Personal IP red lines (don't post about):
- **Specific financial gains** ("我赚了 $X") → triggers envy + future risk
- **Personal grievances about specific people** → unprofessional + creates enemies
- **Hype-y predictions** (unless you'd bet your reputation on it) → erodes Sage credibility
- **Politics / divisive topics** unrelated to your niche → loses audience
- **"Behind the scenes" too soon** → "build in public" can leak strategic intel

---

## Decision flow

```
1. Define 支点优势 (rarest intersection)
   └─ Write 3 candidate niches
   └─ Choose the rarest + most defensible

2. Commit to ONE archetype
   └─ Sage / Hero / Magician / Explorer / etc.
   └─ Write a 1-page "what I'm NOT" list

3. Set 18-month cadence
   └─ Weekly long-form (Substack/Twitter thread)
   └─ Daily short-form (X/LinkedIn)
   └─ No viral chasing, just consistency

4. STEPPS-audit every draft
   └─ Score 0-6, must hit 2+
   └─ If under 2, rewrite

5. Red line scan before publish
   └─ Specific $ amounts? Personal grievances? Politics?
   └─ If yes → cut
```

---

## Anti-patterns to flag

- **Niche-hopping** (3 niches in 6 months = no IP built)
- **Viral chasing** (one viral post ≠ IP; consistency does)
- **Archetype drift** (Sage one week, Hero next week)
- **Audience pleasing** (writing what gets likes instead of what builds depth)
- **Reactive posting** (responding to others' viral takes — adds noise)
- **Hot take addiction** (loses Sage credibility fast)
