## 🎬 同一本书 · 六种读者 · 完全不同的 take-away

拿《影响力》(Cialdini) 来举例——同样的 6 个心理原则，看谁在读：

| 你是谁 | 这本书对你最直白的意思 |
|------|---------------------------|
| 🚀 **准备创业** | Cold email 第一封必带一份 specific report (互惠激活) → 回复率 ×3。**不送先要 = 你在裸奔** |
| 💼 **上班族做副业** | 你免费的内容就是互惠 → 但要给"刚好够用"的，留 30% 在付费版。**全送出去 = 副业死掉** |
| 🎯 **想成为管理层** | 团队"自愿"加班 = 你激活了承诺一致 + 社会认同。**这是权力，不是文化**。别自我感动 |
| 🎓 **学生 / 在学商业** | 教授的"权威"原则一直在影响你。**主动质疑权威 = 你的独立思考训练**——这是商科学生的护城河 |
| 📊 **投资 / 看大势** | Founder pitch 用了几条原则 = 信号。用 1-2 条 = 自然。**用 5 条以上 = 操纵嫌疑，pass** |
| 🌍 **想懂商业运作** | 6 原则就是商业世界的暗操作系统。**看懂之后，你刷小红书时知道每条爆款用了哪 1-2 条** |

**同样 6 条原则。6 种行动。0 句鸡汤、0 处转述。**

这才是"为你读书"的意思。

## 📖 样本 · 《七个习惯》六种人设的不同读法

看 Stephen Covey 这本经典如何按读者角度 re-cut：

### 原文（Covey 的原话）
> *"消极被动的人，言语中就会流露出推卸责任的个性。例如：'我就是这样。'仿佛是说：这辈子注定改不了。"*

### 对你来说意味着什么：

**🚀 准备创业的你读到的是**：  
Founder 唯一不能有的口头禅就是"市场就是这样"。市场是你创造的——你说"市场就这样"那就是你认输了。**这一句话能筛掉 80% 不该投的项目**。

**💼 上班族做副业的你读到的是**：  
"我没时间做副业" / "我没流量" / "我不会写"——每说一次就给副业判一次死刑。**5 年后没做副业的人都是这一句话的受害者**。

**🎯 想成为管理层的你读到的是**：  
"我就是不会带人" / "我们公司不培养中层"——你的影响圈在缩小。**改成"我下个月先带 1 个新人"，影响圈立刻反向扩张**。

**🎓 学生读到的是**：  
"我专业不对口" / "我家里没人脉" / "我学校不够好"——这 3 句话就是大学 4 年的最大陷阱。**主动积极 = 你 18 岁起最该练的核心能力**。

**📊 投资人读到的是**：  
Founder 第一次 pitch 时如果说"市场就这样" / "竞争太激烈" / "时机不好"——直接 pass。他没意识到自己在关注圈里。**这种 founder 救不了**。

**🌍 想懂商业的你读到的是**：  
所有商业奇迹（Apple、Tesla、字节）的起点都是创始人**拒绝接受"行业就这样"**。看懂这一句，你就懂了为什么大部分行业 30 年不变——**因为大部分人接受了**。
